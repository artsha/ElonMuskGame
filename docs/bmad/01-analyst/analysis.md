# Аналитик - Исследование фичи /players

**Роль:** Аналитик
**Проект:** ElonGame Telegram Bot
**Фича:** Команда /players для просмотра списка игроков в комнате
**Дата:** 2026-11-02

## Проблема
Сейчас игроки не могут быстро посмотреть, кто находится в комнате. Участникам неудобно ориентироваться в составе.

## Целевая аудитория
Все участники комнаты (и создатель, и обычные игроки).

## Бизнес-ценность
- Улучшает UX - игроки сразу видят состав комнаты
- Помогает при большом количестве участников
- Не влияет на механику игры

## Требования высокого уровня
1. Любой участник, состоящий в комнате, должен иметь возможность выполнить команду /players
2. Команда должна выводить список всех игроков в текущей комнате
3. Список должен быть читаемым (имена/юзернеймы)
4. Если пользователь не состоит в комнате - выводить сообщение об ошибке

## Ограничения
- Работает только для пользователей, которые находятся в комнате
- Использует существующую структуру БД (таблица room_members)
- Минимальные изменения в коде

## Критерии успеха
- Команда /players работает в рамках комнаты
- Корректно показывает всех участников
- Не ломает существующий функционал
