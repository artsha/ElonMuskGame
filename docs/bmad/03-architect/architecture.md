## Проектируемое решение

### Новый файл
`handlers/players.py` - хендлер команды /players

### SQL запросы
Нужно получить всех участников комнаты с данными пользователя:

```sql
SELECT u.user_id, u.full_name, u.username
FROM room_members rm
JOIN users u ON rm.user_id = u.user_id
WHERE rm.room_id = ?
ORDER BY rm.joined_at ASC
```

### Логика
1. Найти комнату пользователя (по последнему членству как в /room)
2. Если нет комнаты - сообщение об ошибке
3. Получить список участников
4. Отформатировать вывод

### Формат вывода
```
Игроки в комнате ABC123 (3):

1. Иван Петров (@ivan)
2. Мария (@masha)
3. Алексей
```

Если нет username - просто full_name.

## Технические детали
- Использовать существующий паттерн хендлеров
- Без FSM
- Команда доступна в любом статусе комнаты (lobby/round) - как и /room

## Тестирование
- Проверить в комнате с 1, 2, 3 игроками
- Проверить вызов без комнаты
- Проверить с пользователями без username
