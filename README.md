# ElonGame Bot

Телеграм-бот игра "Elon Musk".

## Установка

1. Скопируй `.env.example` в `.env` и укажи `BOT_TOKEN`
2. Установи зависимости:
```bash
pip install -r requirements.txt
```
3. Запусти бота:
```bash
python main.py
```

## Как играть

1. `/create` - создать комнату, нужно ввести свой ID комнаты
2. `/join <ID>` - присоединиться к комнате по ID
3. В лобби все добавляют проблемы через `/addproblem <текст>`
4. Создатель запускает раунд `/startround` - один игрок получит "Elon Musk", остальные - реальную проблему
5. Создатель завершает раунд `/endround` - сыгранная проблема удалится из банка
6. Создатель может удалить комнату `/deleteroom` - комната и все данные удалятся
7. Можно играть новые раунды пока есть проблемы в банке
